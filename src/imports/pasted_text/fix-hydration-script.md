==================================================

==================================================
3. PRERENDER: CORRECT THE HTML BOUNDARY
==================================================

The important correction belongs in:

scripts/prerender.js

The final generated HTML must have this structure:

<body>

  <div id="root">
    <!-- React application markup ONLY -->
  </div>

  <!-- React Router hydration script/data -->
  <script>
    ...
  </script>

</body>

The React Router hydration script MUST NOT be inside #root.

Currently the server-rendered output can contain both:

1. React application markup
2. React Router hydration script

Do not blindly put the entire renderToString() result inside #root.

Instead, separate the rendered React application markup from the React Router hydration script before constructing the final HTML.

Then:

- put only the React application markup inside #root
- place the React Router hydration script immediately after </div>
- keep it before </body>
